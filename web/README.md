# Jack Pockets Studio UI

React + Vite production dashboard for the documentary API.

## Development

1. Install dependencies: npm install
2. Set VITE_API_BASE_URL if the API is not at http://127.0.0.1:8000.
3. Start the UI: npm run dev
4. Build for production: npm run build

The dashboard creates documentary jobs, starts the model roundtable, exposes synthesis for human script review, generates narration, searches and selects Pexels footage, submits a Remotion timeline, and retrieves validated MP4 output.
